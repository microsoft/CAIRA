# CAIRA Learning Katas

Learn CAIRA through hands-on practice with guided katas.

## Getting Started

1. **Install the HVE Learning Extension** in VS Code
2. **Use the `learning-kata-coach` custom agent** to work through CAIRA katas interactively

The kata coach will guide you through practical exercises to master CAIRA deployment patterns and best practices.

## Available Katas

- **caira-fundamentals/** - Core CAIRA concepts and deployment basics
- **troubleshooting/** - Diagnostic and problem-solving techniques

## Starting a Learning Session

Open GitHub Copilot Chat, select the **learning-kata-coach** custom agent, and try:

**Learn from scratch:**
```
"Coach me on CAIRA fundamentals"
```

**Practice troubleshooting:**
```
"Coach me on troubleshooting CAIRA deployments"
```

**Get recommendations:**
```
"What katas are available?" or "Recommend a kata for me"
```
